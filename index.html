Privacy Policy

Application: Break Schedule Builder
Developer: OPS Flow Systems
Effective Date: October 7, 2026

1. Introduction

OPS Flow Systems provides Break Schedule Builder, an Android application designed to create work schedules, organize breaks and meal periods, and manage scheduled reminders. This policy explains how the application handles information.

2. Information Processed

The application processes information entered by users, including employee names, venue or workplace names, shift dates and times, break and meal rules, schedules, and alarm statuses. No account, email address, or password is required to use the application.

3. Local Storage

Scheduling information is stored locally on the Android device using an application database. Core scheduling and reminder features work without an internet connection. OPS Flow Systems does not operate an application server that receives these scheduling records.

4. Android Backups

The application currently allows Android system backup. Depending on device settings and Android versions, locally stored application data may be included in system backups or transferred when changing or restoring devices. These operations are managed by Android and applicable backup providers.

5. Permissions

The application uses notification permissions, exact alarms, full-screen alarm capabilities, device restart detection, and foreground media playback services to deliver reminders, play alarms, and restore eligible scheduled alarms after a restart. Android text-to-speech services may also be used where available.

6. Third-Party Services and Sharing

The reviewed application configuration does not include Firebase Analytics or a dedicated advertising SDK and does not declare Android's INTERNET permission. OPS Flow Systems does not intentionally transmit employee names or scheduling records to its own servers or sell these records to advertisers. Android system services and backup providers may process information under their own privacy practices.

7. Data Retention and Deletion

Scheduling records remain stored on the device until removed using available application controls, Android app-data settings, or by uninstalling the application. Previously created system backups may remain subject to the applicable backup provider's retention policies.

8. Security

The application relies on Android's application storage protections. Users should secure their devices with screen locks and operating system updates. No storage system guarantees absolute security.

9. Children's Privacy

Break Schedule Builder is intended as a workplace productivity application and is not specifically directed toward children.

10. Changes to This Policy

OPS Flow Systems may update this Privacy Policy to reflect changes to the application or its privacy practices. Updates will appear on this page.
